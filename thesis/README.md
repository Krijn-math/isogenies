# The Isogeny Forest

A static page for GitHub Pages. Copy this whole `thesis/` folder into the root of
your Pages repository; it then lives at `https://<your-site>/thesis/`.

## Files

- `index.html` – the page. The form's email address is set near the bottom (`FOREST_CONFIG`).
- `data/graph.json` – the data. `nodes` are people, `edges` go from supervisor (`from`) to student (`to`).
- `assets/` – styles, scripts, and vendored copies of d3 (ISC) and flag-icons (MIT), so nothing loads from a CDN except Google Fonts.
- `thesis_data/<slug>.html` – redirect pages behind short links such as `/thesis/krijn`, generated by the
  script below. They live in `thesis_data/` to keep this folder tidy; the site's root `404.html` forwards
  `/thesis/<slug>` to `/thesis/thesis_data/<slug>.html`, so the short URL works on GitHub Pages.
- `thesis_data/` – also the source data and pipeline: `theses.json`/`theses.csv` (one row per thesis),
  `graph/to_graph.py` (turns `theses.json` into `data/graph.json`, applying `graph/overrides.json`),
  `graph/TO-CHECK.md` (open questions), `src/` and `eprint/` (one-off build scripts and caches).
- `tools/build_links.py` – regenerates the short links from `graph.json`.

## A person in graph.json

```json
{ "id": "krijn", "name": "Krijn Reijnders", "year": 2025,
  "university": "Radboud University", "country": "nl",
  "title": "…", "pdf": "https://…/thesis.pdf", "homepage": "https://…" }
```

- `country` is a two-letter ISO code (lowercase) and shows as a flag.
- `"external": true` marks a supervisor whose own thesis is outside the field (drawn as an open circle, no short link).
- `slug` (optional) overrides the short link. By default it is the first name in lowercase, with 2, 3, … for later namesakes in order of defence year.
- `label` (optional) overrides the "Dr. First Last" heading on the person's card.
- `short` (optional) overrides the name on the node, which by default is the full name without initials or "Jr.".

## After editing graph.json

```sh
python3 tools/build_links.py
```

This creates or updates the short-link pages in `thesis_data/` and removes ones it made earlier that are no longer needed.
Preview locally with `python3 -m http.server` from the repository root and open `http://localhost:8000/thesis/`
(opening `index.html` straight from disk won't load the data). The local server has no 404 forwarding,
so test a short link there as `http://localhost:8000/thesis/thesis_data/krijn.html`.

## Recent papers

Each doctor's card has a "Recent papers on ePrint" dropdown, read from `data/papers.json`.
Refresh it with

```sh
python3 tools/fetch_papers.py
```

The first run harvests the IACR ePrint metadata (OAI-PMH, CC0) year by year and caches it in
`~/.cache/isogeny-forest/`; later runs only fetch what changed. Papers are matched by name, so
check `tools/papers-review.txt` for namesakes and fix them in `tools/papers-config.json`
(`aliases`, `strict`, `exclude`, `skip`; see the top of the script).
